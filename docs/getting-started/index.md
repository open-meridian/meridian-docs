# Getting started

Start here if you have not run Open Meridian before. Work through the pages in order. By the end you
have a deployment in your own cluster, a plugin running in it, and an AI agent that can change that
plugin while you watch.

| Page | What you get |
|---|---|
| [Install a deployment](installation.md) | A running deployment that you and your firm's people sign in to. Uses `meridian doctor`, `meridian up` and the set-up wizard. |
| [Your first plugin](first-plugin.md) | A plugin made from the reference plugin, uploaded, launched and opened in the dashboard. |
| [Build with an AI agent](build-with-an-ai-agent.md) | A development deployment where a coding agent edits your plugin and each save runs in about a second. |

!!! tip "In a hurry?"
    To try Open Meridian on a laptop, install with `--development`. The same deployment then works
    for all three pages. Never use `--development` on a deployment your firm depends on.

Once you are done, the [how-to guides](../how-to/index.md) cover single tasks, and the
[tutorials](../tutorials/index.md) walk through complete examples.
